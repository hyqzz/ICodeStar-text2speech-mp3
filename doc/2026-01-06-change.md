## 本次修改概述

- 修复长文本转换卡在 50% 的问题，支持按片段合成后拼接。
- 增加 ffmpeg 可用性检查与友好提示，避免静默失败。
- 保留进度条显示，优化错误提示与中文界面文案。
- 新增 COM 初始化/释放，异常时输出 HRESULT，便于定位 SAPI 异常。
- 控制台新增 INFO/ERROR 日志，记录分段、拼接及导出进度。
- 去掉对 `SpFileStream.Format` 的自定义设置，改用默认格式，解决 COM 错误 (-2147201022，“发生意外”) 导致的转换失败问题。
- 新增 GUI 设置项：音色下拉框（枚举系统 SAPI 声音）与音质下拉框（高/中/低，对应不同 MP3 比特率），并在合成与导出时应用。
- MP3 生成位置改为与源文本同目录，便于查找。
- 在音色选择后新增“试听”按钮，播放示例文本便于预览当前音色。
- 扩展音色加载逻辑，同时枚举 Desktop 与 OneCore 语音（如 Xiaoxiao、Yunxi 等），并通过 `SpObjectToken` 使用这些音色。
- 修正 OneCore 注册表路径为 `...Speech_OneCore\Voices\Tokens`，使用 `EnumerateTokens("", "")` 正确枚举 Natural 音色。
- 再次修正 OneCore 加载方式：改为直接遍历注册表 `Speech_OneCore\Voices\Tokens` 子键并用 `SpObjectToken.SetId` 创建 Token，避免 COM Category 枚举不完整导致的音色缺失问题。
- 新增 Edge TTS 引擎选项：通过 `edge-tts` 库调用云端自然音色（如 XiaoxiaoNeural），在 GUI 中可选择“本地 SAPI / Edge TTS”，并沿用原有进度条与 MP3 输出逻辑。
- Edge TTS 试听逻辑独立于本地 SAPI：当选择 Edge TTS 引擎时，试听会用 Edge TTS 合成短 mp3 并调用系统播放器播放，避免落回默认 Huihui 本地音色。
