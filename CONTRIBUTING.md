## Contributing to This Project

Thank you for your interest in contributing!  
This project is a simple Windows Text to Speech (TTS) to MP3 tool written in Python.

### How to Get Started

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally.
3. Create a new **feature branch**:

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. Make your changes and commit with a clear message:

   ```bash
   git commit -m "feat: add xxx"   # or fix/docs/chore...
   ```

5. **Push** your branch and open a **Pull Request (PR)** to the `main` branch of this repo.

### What You Can Contribute

- Bug fixes and stability improvements.
- New features (e.g. more TTS options, better UI, more settings).
- Documentation improvements (README, FAQ, examples).
- Refactoring and code style improvements.

If you are not sure whether a feature is suitable, you can first open an **Issue** to discuss it.

### Coding Style

- Prefer clear, readable Python code.
- Keep function and variable names descriptive.
- Add comments where logic is non-trivial (especially around TTS and audio handling).

### Issues

- When reporting a bug, please include:
  - Your Windows version.
  - Python version.
  - Steps to reproduce.
  - Any error messages or screenshots if available.

Thank you again for helping make this Text to Speech (TTS) to MP3 tool better!
